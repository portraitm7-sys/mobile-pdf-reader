# Mobile PDF Reader

A clean offline PDF reader built with Flutter.

## Included features

- Open PDF files from the phone file picker
- Copy imported PDFs into the app's own documents directory
- Recent files
- Favorites
- Remember the last page for each PDF
- Search inside text-based PDFs
- Jump directly to a page number
- Pinch zoom and smooth scrolling
- Light / dark app theme
- Delete locally imported PDFs
- Android and iOS-ready Flutter source

## Requirements

This project uses `pdfrx 2.6.x`, which requires a recent Flutter toolchain. Use Flutter 3.47+ / Dart 3.13+.

## First-time setup

This ZIP contains the app source and project configuration, but generated Flutter platform folders are intentionally not committed because they are best generated by your installed Flutter version.

From the project folder run:

```bash
flutter create --platforms=android,ios .
flutter pub get
flutter run
```

If you only want Android:

```bash
flutter create --platforms=android .
flutter pub get
flutter run
```

## Build Android APK

```bash
flutter build apk --release
```

APK output:

```text
build/app/outputs/flutter-apk/app-release.apk
```

## Build Android App Bundle for Google Play

```bash
flutter build appbundle --release
```

## Upload to GitHub

```bash
git init
git add .
git commit -m "Initial PDF Reader app"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/mobile_pdf_reader.git
git push -u origin main
```

## Main dependencies

- `pdfrx` — PDF rendering, zoom, page navigation and text search
- `file_picker` — native file selection
- `path_provider` — app documents directory
- `shared_preferences` — recent/favorite/page/theme metadata

## Notes

- Search works for PDFs that actually contain text. Image-only/scanned PDFs need OCR, which is not included in this first version.
- Imported PDFs are copied into the app's local documents directory so they stay available in Recent files.
- The generated Android/iOS folders can be committed to GitHub after running `flutter create`.
